# Pagina web de Tocar Madera 

## Descripcion 
una pagina web Ecomerce para artesanos de la madera de chile. 

## Tecnologias 
-html5, css3, javascript (Vanilla)
-Boostrap por Cdn
## ejecutar 
Ejecutar proyecto desde index.html en navegador, desde live serve (Recomendado) 

## funcionalidades 
-Nav bar para navegar por sus paginas
-listado de productos en tarjetas on botones de compra, en zona de productos
-Footer con informacion de la tienda. 
-pagina de detalle de producto
-carrito de compra como estructura
